# 🎬 治愈系单词放映机 - AI Agent 大赛参赛文档

## 项目概述

**项目名称**：治愈系单词放映机 (Healing Vocabulary Cinema)  
**项目版本**：2.0.0  
**核心定位**：将英语单词化作治愈系爱情故事，在沉浸式感动中完成词汇记忆

---

## 🎯 创新亮点

### 1. **多智能体协作架构**
采用三个专业AI Agent协同工作：
- **🎬 WordAnalyzer（词语拆解者）**：从单词中挖掘电影般的画面感和情感共鸣
- **✍️ StoryWriter（治愈系编剧）**：创作具有文艺电影感的治愈系爱情故事
- **⚖️ StoryJudge（放映机评委）**：从电影美学和词汇教学双重维度进行质量评审

### 2. **质量控制机制**
- **评分系统**：满分100分，5个维度的专业评审
- **重写机制**：85分以下自动重写，最多2次改进机会
- **反馈闭环**：评委提供具体改进建议，编剧针对性优化

### 3. **教育创新价值**
- **情境记忆法**：单词在故事场景中自然出现，而非生硬背诵
- **多感官联想**：视觉、听觉、嗅觉、触觉全方位记忆锚点
- **情感共鸣强化**：通过故事情感加深词汇记忆深度

### 4. **文艺美学追求**
- **电影级质感**：追求新海诚动画、《爱乐之城》般的画面感
- **治愈系基调**：细水长流、双向奔赴、彼此救赎的温暖主题
- **感官细节**：光影、色彩、声音、触感的细腻描写

## 📋 技术架构

### 配置文件结构
```json
{
  "name": "治愈系单词放映机",
  "agents": [WordAnalyzer, StoryWriter, StoryJudge],
  "workflow": [7个步骤的完整工作流],
  "features": {
    "vocabulary_learning": "高考3500词汇、四六级词汇",
    "story_style": "爱情治愈系、文艺电影感",
    "quality_control": "85分及格线、最多2次重写"
  }
}
```

### 工作流程
1. **词语拆解** → WordAnalyzer分析4个单词的浪漫意象和融入方案
2. **故事创作** → StoryWriter创作400-600字的治愈系爱情故事
3. **质量评审** → StoryJudge进行5维度评分，85分以下进入重写流程
4. **故事重写** → 根据反馈改进（最多2次）
5. **最终输出** → 完整故事 + 词汇卡

## 📊 评审标准（5维度）

| 维度 | 分值 | 评价要点 |
|------|------|----------|
| 词汇融入度 | 25分 | 单词是否自然融入场景，无生硬感 |
| 电影感与画面感 | 25分 | 画面是否如电影分镜，光影色彩描写 |
| 情感治愈力 | 25分 | 是否温暖动人，结局是否有力量 |
| 文艺质感 | 15分 | 语言是否优美细腻，文艺气息 |
| 格式规范 | 10分 | 是否符合输出格式要求 |

**评分等级**：
- 90-100分：电影级作品
- 85-89分：优秀作品（通过线）
- 70-84分：合格作品（需重写）
