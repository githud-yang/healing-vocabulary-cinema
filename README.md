# 🎬 治愈系单词放映机 (Healing Vocabulary Cinema)

> 将英语单词化作治愈系爱情故事，在沉浸式感动中完成词汇记忆

## 🌟 项目概述

**治愈系单词放映机**是一个多智能体协作系统，通过三个专业AI Agent的协作，将英语单词转化为具有电影级质感的治愈系爱情故事。

### 三个AI Agent协作

- **🎬 WordAnalyzer（词语拆解者）**：从单词中挖掘电影般的画面感和情感共鸣
- **✍️ StoryWriter（治愈系编剧）**：创作具有文艺电影感的治愈系爱情故事
- **⚖️ StoryJudge（放映机评委）**：从电影美学和词汇教学双重维度进行质量评审

## ✨ 核心特色

- **🎨 电影级质感**：追求新海诚动画、《爱乐之城》般的画面感
- **💝 治愈系基调**：温暖、唯美、细腻的爱情故事
- **📝 教育创新**：情境记忆法，让单词在故事中"活"起来
- ⚖️ **质量保障**：5维度评分 + 自动重写机制
- **🌐 多模态输出**：支持文本、语音、视觉卡片

## 🚀 快速开始

### 环境要求
- Python 3.6+
- OpenAI API Key 或其他大模型API（如千问API）
- requests 库（用于 API 调用）

### 安装步骤
1. 克隆本仓库
2. 安装 Python 依赖：
   ```bash
   pip install requests
   ```
3. 配置API Key（在 `demo.py` 中设置）

### 使用方法

#### 运行演示脚本
```bash
python demo.py
```

输入 4 个英语单词，即可生成治愈系爱情故事

## 🔧 工作原理

1. **词语拆解**：WordAnalyzer分析 4 个单词的浪漫意象和融入方案
2. **故事创作**：StoryWriter创作 400-600 字的治愈系爱情故事
3. **质量评审**：StoryJudge进行5维度评分，85分以下进入重写流程
4. **故事重写**：根据反馈改进（最多 2 次）
5. **最终输出**：完整故事 + 词汇卡

## 🎨 核心约束

- **绝不生硬中英夹杂**：单词作为场景元素自然融入
- **电影级质感**：注重光影、色彩、声音、触感的描写
- **治愈系基调**：温暖、唯美、细腻的情感表达
- **规范格式**：标题 + 正文 + 词汇卡的标准格式

## 🌱 应用场景

- 📚 **高考备考**：3500 词汇的情境记忆
- 🎓 **四六级备考**：高频词汇的深度学习
- ✍️ **创意写作**：提供故事创作灵感
- 💝 **情感治愈**：温暖治愈的爱情故事
